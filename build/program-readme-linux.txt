SHADOWTRACE TOOLKIT - HOW TO OPEN IT ON LINUX

Run it in a terminal from this folder:

    ./shadowtrace-toolkit

Or, in many file managers, right-click "shadowtrace-toolkit" and choose
"Run in Terminal" (or "Run as a Program"). A menu appears; press Enter for the
standard check. No Python install is needed.

Do not run it with sudo: it checks your own account's browsers and files.

Check the download first if you can: compare its SHA-256 with the release page,
or run  gh attestation verify <file> --repo manilreddy1/ShadowTrace
Guide: https://github.com/manilreddy1/ShadowTrace#readme
