🛡 How to Bypass Antivirus False Positives Safely

Windows Defender SmartScreen: "Windows protected your PC"

This appears for newly released programs that are not yet code-signed with a paid corporate EV certificate.

  1. Click More info under the warning banner.
  2. Click the Run anyway button that appears.
  3. The scanner window will open safely.
Windows Defender Removed the File into Quarantine

If Microsoft Defender deleted the file without asking:

  1. Open Windows Security → Virus & threat protection → Protection history.
  2. Find the entry for shadowtrace-toolkit, click it, and choose Actions → Restore.
  3. Double-click the file to run it.
macOS Gatekeeper: "Cannot be opened because Apple cannot check it"

macOS stops apps from opening the first time if they are not notarized by Apple:

  1. Open System Settings → Privacy & Security.
  2. Scroll down to the message: "ShadowTrace Toolkit was blocked from use because it is not from an identified developer".
  3. Click Open Anyway, type your password, and click Open.
Giving Full Disk Access on macOS (for Safari & Mail check)

To allow the check to read Safari and Apple Mail records:

  1. Go to System Settings → Privacy & Security → Full Disk Access.
  2. Click the + button, choose Applications → ShadowTrace Toolkit (or Terminal if running via Python), and toggle it ON.
